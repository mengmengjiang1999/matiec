## Context

Top-level programs and tests intentionally name sources below `compiler/` and
`tests/`. Without `subdir-objects`, Automake currently places their objects at the
top level and warns that this compatibility behavior may change.

## Decisions

- Add `subdir-objects` to the existing `AM_INIT_AUTOMAKE` option set.
- Keep target-specific object names generated by Automake rather than manually
  flattening paths.
- Let `in_memory_generator_test` obtain `CompilationContext` from
  `compiler/libcompiler.a`, which it already links.

## Risks / Trade-offs

Object paths change, so stale configured trees are not representative. Validation
must start from `distclean` and include an out-of-tree build to exercise generated
dependency paths.
