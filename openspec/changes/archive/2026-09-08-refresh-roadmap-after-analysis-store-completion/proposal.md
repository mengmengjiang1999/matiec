## Why

The Analysis Store migration is complete, but the public roadmap still lists
context-owned semantic storage as future work and the standards roadmap presents
completed foundation steps as pending. The documentation must distinguish
completed architecture from genuine future boundaries.

## What Changes

- Mark the Analysis Store architecture track complete in the README roadmap.
- Recast the IEC evolution sequence as completed foundations plus remaining work.
- Require reader-facing roadmap summaries to agree with maintained implementation
  evidence and archived OpenSpec changes.
- Update architecture and decision cross-references where they describe the next
  transition step.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `language-conformance-traceability`: Require roadmap status summaries to stay
  aligned with maintained feature and implementation evidence.

## Impact

Documentation and the language-conformance traceability specification change. No
compiler behavior, generated output, or public API changes.
